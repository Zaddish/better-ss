# BetterSS

I got sick and tired of the dogshit windows snipping tool's animation delays and shitty captures not being able to let me just save a file directly or add it to my clipboard on 1 press.

I also hated all the bullshit that lightshot and shareX have. I do not need the bloat, nor do I _need_ their features.

You can capture region screenshots with a hotkey, add annotations to them, and save them to a file or copy them to your clipboard. It also doesn't include and exif data, and doesn't automatically save the image just because you pressed the hotkey
